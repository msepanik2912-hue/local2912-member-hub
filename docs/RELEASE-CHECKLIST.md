# Pilot and release checklist

Record checker, date, browser/device and result. These human checks are not pre-certified by this package.

- [ ] Actions passes; Pages URL works signed out with the repository path.
- [ ] PDFs and all repository files are approved for distribution; no private contacts, cases, secrets or actual admin settings.
- [ ] HTML contract reader and search work. CBA-first governance and conditional supplemental precedence remain; PDF links and source-version labels are accurate.
- [ ] Re-run the 78-question suite after source changes; review deadlines, wages, tables, probation and grievances manually. Extraction alone does not verify scanned pages/tables.
- [ ] Authorized Google admin can analyze/draft/compare/activate/archive/rollback; disallowed and signed-out users are denied. Allowlist/caller identity works in the actual deployment.
- [ ] Public endpoints are read-only. Test invalid and unavailable feeds and complete bundled-source fallback.
- [ ] Board/steward data is approved; calendar dates/downloads, department routing, links and announcement expiry work, or empty sections honestly say Not connected.
- [ ] Ask 2912 shows excerpts and editable prepared prompt; copy success/failure is announced. ChatGPT opens without sending question text; members paste into their own account. No Local-funded API.
- [ ] Keyboard-only: skip link, routes, reader, search, copy/edit and calendar controls work; focus remains visible and follows route headings.
- [ ] Blind member's screen reader: headings, labels, citations and completed-result/status announcements are understandable.
- [ ] Narrow mobile width and 200%/400% zoom do not hide essential text/controls; verify contrast and reduced motion.
- [ ] Added video has reviewed captions and transcript; audio has transcript. Key rights/training media provides ASL where feasible as a supplement to captions. Alerts never depend solely on sight/hearing.
- [ ] Offline after online load: rights and search work; previously opened PDFs work; live data is not mislabeled.
- [ ] Installed Stage 8 upgrade and rollback tested with close/reopen; other sites on the same Pages domain unaffected.
- [ ] Small member pilot completed, issues resolved, release ZIP/tag saved, and Pages address ready for broad sharing.
